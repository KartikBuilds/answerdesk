## Accounting software
Ledgerly connects to Xero and QuickBooks Online on the Pro plan. Paid invoices and payments sync every hour.

## Zapier
Use the Ledgerly app on Zapier to connect other tools, for example to post a message when an invoice is paid. Available on all plans.

## API
A REST API is available on Pro for building your own integrations. Create API keys under Settings, then Developers. Requests are limited to 100 per minute per account.
